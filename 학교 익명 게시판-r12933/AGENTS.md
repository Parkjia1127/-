## 이 앱

스쿨라운지는 학교 익명 게시판이다. 처음에는 입장 승인 요청 화면이 열린다. 이메일 없이 닉네임과 비밀번호로 로그인하고 요청을 보내면 대기 화면이 나타난다.
‘처음 이용하기’에서 공개 초기 비밀번호 1111을 거쳐 새 비밀번호를 저장한다. 새 일반 회원 비밀번호는 12~19자, 새 운영자 비밀번호는 24자 이상이다. 이미 등록한 비밀번호는 그대로 쓸 수 있다. 1111은 등록 안내에만 쓰며 기존 계정 로그인이나 복구에는 사용할 수 없다.
승인된 계정만 게시판을 쓸 수 있고, 승인 여부는 계정에 남는다. 브라우저 로그인은 90일 동안 유지된다.
삽입된 미리보기에서도 로그인 상태를 유지하도록 분할 쿠키를 사용한다. 쿠키가 막혀 있으면 비밀번호를 확인한 뒤 같은 탭에서 최대 1시간 로그인 상태를 유지한다. 탭 저장소까지 막힌 경우 새로고침하면 다시 로그인해야 할 수 있다.
운영자는 입장 승인·거절·취소와 게시물 관리자 권한 부여·회수, 관리자 삭제 기록 조회, 기본 문구 편집을 맡는다.
게시물 관리자는 다른 사람의 글과 댓글을 삭제할 수 있다. 회원은 자기 글과 댓글만 삭제할 수 있다.
게시글·댓글·대댓글은 본인만 수정할 수 있다. 내용을 바꾸면 게시판에 ‘수정됨’이 표시되며, 변경 전 내용은 따로 보관하지 않는다. 작성자는 삭제 전 확인창을 거친다.
게시글에서 계정당 좋아요·싫어요 하나를 선택하거나 취소할 수 있다. 승인된 회원은 각 반응의 총개수와 본인 선택을 볼 수 있다. 반응 버튼 아래에 열람 안내는 표시하지 않으며, 운영자만 ‘반응 내역 보기’에서 가입 닉네임과 반응을 본다. post_reactions는 현재 선택만 저장하며 글을 지우면 함께 삭제된다.
글쓴이가 자기 글에 쓴 댓글과 답글은 ‘글쓴이’로 표시한다. 운영자만 글 상세에서 게시글·댓글·대댓글 작성자의 가입 닉네임을 바로 볼 수 있고, 게시글 작성자 목록도 볼 수 있다. 일반 회원과 게시물 관리자에게는 가입 닉네임을 보내지 않는다. 삭제된 원댓글에는 닉네임을 표시하지 않는다.
익명성 안내, 대댓글 보기 버튼, ‘글쓴이’ 표시를 문구 편집으로 바꿀 수 있다. 게시판에는 저장한 익명성 안내만 표시하고, 실제 닉네임 열람 권한은 회원가입 화면에서 안내한다.
댓글에 한 단계 답글을 달 수 있다. 원댓글을 삭제해도 답글은 남고, 글을 삭제하면 댓글과 답글도 삭제된다. 목록과 글 상세에서 작성 중인 입력을 유지하며 새로고침할 수 있다.
accounts는 입장 상태·역할, nickname_credentials는 닉네임과 솔트를 적용한 비밀번호 해시, sessions는 로그인 쿠키의 해시와 만료, posts와 comments는 게시물과 소유권을 저장한다.
comment_replies는 답글과 원댓글의 연결, 답글 작성 계정을 저장한다.
deletion_log는 관리 권한으로 삭제한 사람과 시간, site_copy는 운영자가 변경한 문구를 저장한다.
문구 편집 모드에서 화면의 문구나 버튼을 누르면 편집창이 열린다. 전체 문구에서는 다른 입장 상태 화면의 글도 수정할 수 있다.
운영자는 ‘주의 문구 설정’에서 문구를 저장하거나 숨긴다. 설정한 문구는 승인된 회원에게 게시글 목록과 글 상세 상단에 표시된다.
주의 문구 아래 ‘추가 안내’는 기본으로 접혀 있다. 운영자는 ‘추가 안내 본문 설정’에서 본문을, 문구 편집 모드의 ‘전체 문구’에서 제목과 본문을 바꿀 수 있다.
운영자의 ‘초기 화면 편집’에서 로그아웃하지 않고 방문자 입장 화면과 승인 대기 화면을 직접 보고 문구를 수정한다.
설치 안내는 아이폰과 안드로이드 방법을 각각 보여 준다. PWA는 글과 댓글을 오프라인에 저장하지 않는다.
운영자의 ‘앱 꾸미기’에서 홈 화면 설치 이름과 앱 아이콘, 입장 화면 일러스트를 바꾼다. 이미지는 공개 HTTPS 주소를 사용하며 아이콘은 512×512 PNG다. 기존에 설치된 앱은 이름과 아이콘을 갱신하려면 다시 추가해야 할 수 있다. settings는 이 앱 꾸미기 값을 저장한다.
기본 앱 아이콘은 사용자가 첨부한 분홍색 Danganronpa Party 이미지다. 브라우저 탭, 게시판 상단, 홈 화면 설치 아이콘에 적용하며 입장 화면 일러스트는 바꾸지 않는다.
‘내 화면 색감’의 기본은 기존 로즈와 같은 ‘단파티’다. 디저트 테마 16종을 제공하며 감초젤리는 다크 모드다. 삭제된 색을 골랐던 브라우저에는 단파티가 적용된다. 색감은 이 브라우저에만 저장한다.
승인된 회원의 ‘내 알림’에는 다른 사람이 내 글에 단 댓글과 내 댓글에 단 대댓글이 표시된다. 알림 목록과 읽음 상태는 계정별로 저장한다. 휴대폰 푸시는 기기에서 직접 켜며, 로그아웃하거나 로그인이 만료되면 해당 기기에는 보내지 않는다. 잠금 화면에는 작성자와 글·댓글 내용이 없다. 아이폰은 홈 화면에 추가해 열어야 한다.
‘모두 읽음’은 아직 화면에 불러오지 않은 알림까지 내 계정에서만 읽음으로 표시한다. ‘테스트 푸시 보내기’는 해당 기기에만 테스트 알림을 보낸다. 발송 성공 안내는 발송 서비스가 받아들였다는 뜻이며 잠금 화면의 표시까지 보장하지 않는다.
‘읽은 알림 삭제’를 확인하면 아직 불러오지 않은 항목까지 내 계정의 읽은 알림만 모두 삭제하고 개수를 안내한다. 안 읽은 알림, 다른 계정의 알림, 원래 게시글·댓글·대댓글은 그대로 남는다.
첫 운영자가 없으면 입장 화면에 ‘운영자 최초 설정’이 나타난다. 최소 24자의 별도 설정 코드가 있어야 계정을 만들 수 있고, 만들면 승인 없이 바로 들어간다. 운영자 계정이 생기면 코드를 다시 사용할 수 없다. 초기 비밀번호 1111만으로는 운영자가 될 수 없다.
일반 회원으로 로그인한 상태에서도 운영자 최초 설정으로 갈 수 있다. 기존 회원 권한을 자동으로 바꾸지 않고, 다른 닉네임으로 운영자 계정을 만든다.
미리보기에서 미리 준비한 첫 운영자 계정은 저장한 코드로 한 번만 인수한다. 인수 전에는 로그인할 수 없고, 인수할 때 정한 닉네임과 새 비밀번호로만 로그인한다.
미리보기와 공개 링크의 계정은 별도로 저장된다. 공개 링크에서 첫 운영자 설정과 회원가입을 각각 해야 한다. 새 비밀번호 해시는 공개 링크에서 지원하는 형식으로 저장하고, 미리보기의 기존 비밀번호도 그대로 읽는다.
Google 로그인과 이메일 입력을 제거했다. 24자 미만의 운영자 설정 코드로는 최초 설정을 열 수 없다. 이메일을 받지 않으므로 이메일 기반 비밀번호 찾기는 없다.
운영자의 ‘앱 꾸미기 → 링크 공유 미리보기’에서 공유 제목과 소개를 저장한다. 비워 두면 기본 문구를 쓰고 공유 이미지는 그대로다. 게시글과 회원 정보는 공유 미리보기에 표시되지 않는다. 카카오톡에 이전 카드가 남으면 공유 미리보기 캐시를 갱신할 수 있다.
